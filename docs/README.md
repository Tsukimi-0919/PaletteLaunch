# Custom Launcher Project

特定のゲームやアプリケーションを素早く起動するための、カスタマイズ可能なデスクトップランチャーです。

## 特徴

- **マルチテーマ対応**: Valorant風、紫陽花風など、CSS変数による柔軟な着せ替え。
- **2種類の表示モード**: 「標準（名前あり）」と「小（アイコンのみ）」の切り替え。
- **多言語対応**: 日本語と英語を標準サポート。
- **pywebview連携**: Pythonバックエンドとフロントエンドのシームレスな通信。

## セットアップ

1. Python環境の構築 (`pip install pywebview`)
2. `main.py` を実行して起動

# テーマとサイズの仕様

## CSS変数 (CSS Variables)

各テーマは以下の変数を定義する必要があります。

- `--bg-color`: 全体の背景色
- `--accent-color`: カテゴリ線やホバー時のアクセント色
- `--card-bg`: パネルの背景色
- `--text-main`: メインの文字色

## 表示サイズ (Card Sizes)

現在、以下の2種類をサポートしています。

| サイズ | ラベル | 特徴 |
| :--- | :--- | :--- |
| `small` | 小 | アイコンのみ表示 (64x64px)。密度重視。 |
| `medium` | 標準 | アイコンとアプリ名を表示。視認性重視。 |

> **注意**: `small` サイズ時は CSS の `transform: translateY` 等でカテゴリ名の微調整を行っています。

# PaletteLaunch
A launcher with multiple themes

## 仮ドキュメント

### 📖 使い方 (Usage)

#### **1. カテゴリーの作成**

- 画面上部の **「+ CATEGORY」** ボタンをクリックします。
- カテゴリー名（例：Games, Work, Tools）を入力して保存します。

#### **2. ショートカット（アプリ）の登録**

- 登録したいカテゴリーの **「+」** アイコンをクリックします。
- ファイル選択ダイアログが開くので、登録したいアプリの実行ファイル（`.exe` など）を選択します。
- アイコンと名前が自動的に取得され、パネルに追加されます。

#### **3. 整理・並び替え**

- **移動**: ショートカットやカテゴリーは、ドラッグ＆ドロップで自由に並び替えが可能です。
- **編集**: 名前をクリックすると、その場で名称を編集できます。
- **削除**: 右上の「×」ボタンから削除できます。
